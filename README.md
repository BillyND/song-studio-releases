# Song Studio: old releases

Song Studio has moved to **[BillyND/song-studio](https://github.com/BillyND/song-studio)**. New versions, the update feed and the install guide are all there.

This repository is archived. It keeps versions 1.0.1 to 1.0.16 so that older copies of the app can still update. Version 1.0.16 switches them over to the new repo automatically, so there is nothing you need to do.
